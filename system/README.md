# System configuration

The system entrypoint is [`../configuration.nix`](../configuration.nix).
This directory is reserved for system-level documentation and future modules; it is intentionally separate from the Home Manager modules under [`../home`](../home).

The top-level configuration imports:

- [`hardware-configuration.nix`](../hardware-configuration.nix), generated by NixOS for the boot device;
- [`partitions.nix`](../partitions.nix), for additional workstation mounts; and
- [`steam`](../steam), for Steam services and firewall settings.
