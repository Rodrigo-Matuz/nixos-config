# Fastfetch

Enables Fastfetch and installs the checked-in JSONC configuration at
`~/.config/fastfetch/config.jsonc`. Edit [`config.jsonc`](config.jsonc) to
change displayed modules, colors, or layout.

## Upstream and original Nix source

- [Fastfetch](https://github.com/fastfetch-cli/fastfetch) — application and configuration reference.
- [Home Manager Fastfetch module](https://github.com/nix-community/home-manager/tree/master/modules/programs) — original Nix module source.
- [Home Manager option reference](https://nix-community.github.io/home-manager/options.xhtml#opt-programs.fastfetch.enable) — available options.
