# Nuclear music player

Optional module for the Nuclear music player. It uses Rodrigo Matuz's pinned
fork, which packages the upstream application for this configuration.

It is not active on the workstation. To use it there, move this folder to
`home/nuclear/` and rebuild, or select it in a portable installation. Check the
build before switching when the upstream release changes; the package version
and hash are pinned in the flake input.

Learn more: [Nuclear](https://github.com/nukeop/nuclear)
