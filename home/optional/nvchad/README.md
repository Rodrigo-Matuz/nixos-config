# NvChad

Optional Neovim setup using the NvChad Home Manager module. It is separate from
the active custom Neovim configuration in `home/nvim/`.

Choose one, not both. To enable NvChad on the workstation, move this folder to
`home/nvchad/` and rebuild. The portable installer can offer it directly.

Learn more: [NvChad](https://github.com/NvChad/NvChad) ·
[nix4nvchad](https://github.com/nix-community/nix4nvchad)
