# Zen Browser

Optional module that installs Zen Browser and leaves its profile preferences to
the browser itself.

It is not active on the workstation. Move this folder to `home/zen-browser/` or
select it in the portable installer when you want it.

Learn more: [Zen Browser](https://zen-browser.app/) ·
[Zen Browser flake](https://github.com/0xc000022070/zen-browser-flake)
