# Noctalia shell

A saved Noctalia shell configuration with the Matuz dark palette, wallpaper
support, and monitor-specific bar placement.

It is currently parked as an optional module because this repository does not
yet declare Noctalia's flake input. Do not move it into `home/` until that input
and its Home Manager module have been added and locked.

The local palette is [`palettes/Matuz.json`](palettes/Matuz.json).
