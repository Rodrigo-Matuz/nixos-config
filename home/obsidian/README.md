# Obsidian

Installs Obsidian from the pinned nixpkgs package. Vaults, accounts, plugins,
and notes remain yours; this module does not create or synchronize a vault.

The package is unfree, so the profiles already allow unfree packages. The
module is active on the workstation and can be selected during portable
installation.

Learn more: [Obsidian](https://obsidian.md/)
