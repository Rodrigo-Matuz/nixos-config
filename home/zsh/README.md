# Zsh shell

Configures the workstation's Zsh environment with fzf, lsd, zoxide, yazi,
direnv, Atuin, Bun, and a custom Molokai color theme. Aliases and plugins live
in [`aliases.nix`](aliases.nix) and [`plugins.nix`](plugins.nix).

The module also contains the shell startup behavior used by the workstation.
Read it before selecting Zsh on a machine where you already have a carefully
managed shell setup. It is active on the workstation and can be selected in a
portable profile.
