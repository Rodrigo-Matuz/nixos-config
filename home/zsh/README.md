# Zsh shell

Configures Zsh-related tools including fzf, lsd, zoxide, yazi, vivid with a custom Molokai theme, direnv with nix-direnv, atuin, Bun, aliases, and plugins.

## Module

This module is available to be imported by [`../matuz.nix`](../matuz.nix). The implementation lives in [`default.nix`](default.nix).

## Dependencies

`aliases.nix`, `plugins.nix`, and `custom-molokai.yml`

## Customization

Edit `default.nix` and keep this README current when the module's behavior or external inputs change.
