# VSCodium

Installs VSCodium with the Sweet Dracula Monokai theme, Catppuccin icons,
JetBrains Mono Nerd Font, trusted schema domains, and the development extensions
listed in [`default.nix`](default.nix).

The workspace trust choice and schema allowlist are personal workstation
preferences. Review them before reusing the module on a machine shared with
other people.

The module is active on the workstation and can be selected during portable
installation. Extension packages come from
[nix-vscode-extensions](https://github.com/nix-community/nix-vscode-extensions).
