# Zathura

Optional [Zathura](https://pwmt.org/projects/zathura/) document reader from
pinned [nixpkgs](../../flake.nix). On this workstation it is not imported;
uncomment `./zathura` in [`home/matuz.nix`](../matuz.nix) to install it. The
portable installer offers the module independently. No PDF MIME default is
managed here, so omitting it will not replace an existing PDF viewer.
