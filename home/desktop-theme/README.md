# Dark desktop theme

Applies the Matuz dark appearance to GTK and Qt applications. It selects the
Fantasy icon theme, the Matuz GTK colors, KDE's dark color scheme, and Breeze
widgets.

The GTK files are in [`gtk-3.0/`](gtk-3.0/) and [`gtk-4.0/`](gtk-4.0/). After a
rebuild, close open file dialogs and restart the GTK portal, or log out and back
in, so long-running portal processes load the new CSS.

Customize the colors in the files above. The module is active on the
workstation.
