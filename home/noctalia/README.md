# Noctalia shell

Enables Noctalia with a dark custom Matuz palette, wallpaper support, monitor-specific bar settings, and the checked-in palette file.

## Module

This module is available to be imported by [`../matuz.nix`](../matuz.nix). The implementation lives in [`default.nix`](default.nix).

## Dependencies

`palettes/Matuz.json` and the Noctalia flake input

## Customization

Edit `default.nix` and keep this README current when the module's behavior or external inputs change.
