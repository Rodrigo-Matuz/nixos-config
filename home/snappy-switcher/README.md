# Snappy Switcher

Installs Snappy Switcher, starts its user service with the graphical session,
and binds it to `Alt+Tab` in Hyprland.

The generated config and Matuz theme live under
`~/.config/snappy-switcher/`. The theme uses transparent dark cards so the
wallpaper remains visible.

The module is active on the workstation. It needs the pinned
[Snappy Switcher](https://github.com/OpalAayan/snappy-switcher) flake input and a
Hyprland session.
