# Vesktop and Vencord

Installs Vesktop with a declarative Vencord preference set and a Hyprland
launcher entry. The settings cover interface tweaks, media tools, translation,
privacy options, code blocks, and Rich Presence links.

Some settings contain personal Discord server or channel identifiers. Replace
them before reusing this module. The Vencord settings schema can change when
Vesktop updates, so check the generated configuration after upgrades.

The module is active on the workstation and assumes a graphical Hyprland
session.

Learn more: [Vesktop](https://github.com/Vencord/Vesktop) ·
[Vencord](https://github.com/Vendicated/Vencord)
