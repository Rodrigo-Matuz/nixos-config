# Equibop

Installs Equibop, the Discord client used by this setup. On first activation the
module seeds the Caelestia voice setting; after that, it leaves the writable
Equibop settings file alone so your changes are not overwritten.

The module is active on the workstation and can be selected during portable
installation. It is separate from the Vesktop settings, although both are
Discord clients.

Learn more: [Equibop](https://github.com/Rodrigo-Matuz/Equibop)
